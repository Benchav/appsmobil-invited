Algoritmo Python

Formación Aleatoria de Equipos

Los equipos se formarán en vivo el día del evento usando este algoritmo de Python. ¡La aleatoriedad garantiza igualdad para todos!

¿Cómo se formarán los equipos?

El día del evento, todos los estudiantes registrados serán agrupados de forma completamente aleatoria mediante un algoritmo de Python. Esto garantiza que cada equipo tenga una composición diversa y equitativa.

  • 🐍

    Algoritmo en Python

    Uso de la librería random para shuffle y distribución equitativa de participantes

  • 🎲

    Totalmente Aleatorio

    Ningún estudiante sabrá de antemano en qué equipo quedará ni con quién trabajará

  • ⚖️

    Distribución Equitativa

    Los equipos se balancean en tamaño para garantizar fair play entre todos

  • 📊

    Revelación en Vivo

    El algoritmo se ejecutará en directo durante la ceremonia de apertura

Código de Ejemplo 
import random
from collections import defaultdict

def form_teams_compact(participants, team_size=6):
    """
    participants: lista de dicts con keys 'nombre','area','anio','carrera'
    Retorna: lista de equipos (cada equipo es una lista de participantes)
    """
    # 1) crear pools por área (Sistemas solo 4/5 año según regla)
    sis   = [p for p in participants if p.get('area') == 'Sistemas' and p.get('anio') in (4,5)]
    ing   = [p for p in participants if p.get('area') == 'Ingenieria']
    eco   = [p for p in participants if p.get('area') == 'Economicas']
    hum   = [p for p in participants if p.get('area') == 'Humanidades']
    other = [p for p in participants if p.get('area') not in ('Sistemas','Ingenieria','Economicas','Humanidades')]

    # 2) mezclar
    random.shuffle(sis); random.shuffle(ing); random.shuffle(eco); random.shuffle(hum); random.shuffle(other)
    pools = {'sis': sis, 'ing': ing, 'eco': eco, 'hum': hum, 'oth': other}

    teams = []

    # 3) formar equipos priorizando los roles obligatorios: 2xSistemas + 1xIngenieria
    while len(pools['sis']) >= 2 and len(pools['ing']) >= 1:
        team = [pools['sis'].pop(), pools['sis'].pop(), pools['ing'].pop()]
        if pools['eco']: team.append(pools['eco'].pop())
        if pools['hum']: team.append(pools['hum'].pop())
        # rellenar hasta team_size desde la pool con más remanente
        while len(team) < team_size:
            name, lst = max(pools.items(), key=lambda kv: len(kv[1]))
            if not lst: break
            team.append(lst.pop())
        teams.append(team)

    # 4) distribuir sobrantes intentando maximizar diversidad por 'carrera'
    leftovers = [p for lst in pools.values() for p in lst]
    by_career = defaultdict(list)
    for p in leftovers:
        by_career[p.get('carrera','')].append(p)

    for career, studs in by_career.items():
        for s in studs:
            candidates = [t for t in teams if len(t) < team_size]
            if not candidates:
                teams.append([s])
                continue
            def career_count(t): return sum(1 for m in t if m.get('carrera') == career)
            best = min(candidates, key=lambda t: (career_count(t), len(t)))
            best.append(s)

    return teams

FAQ

Preguntas Frecuentes

¿Ya estoy inscrito para el evento?

Sí, todos los estudiantes que completaron el proceso de registro previo ya están confirmados. No necesitas hacer nada más, solo asistir el día del evento. ¡Te esperamos!

¿Puedo elegir mi equipo?

No. La esencia del evento es que los equipos se formen aleatoriamente mediante el algoritmo de Python. Esto garantiza igualdad y fomenta el trabajo con personas de diferentes carreras y habilidades.

¿Qué debo llevar el día del evento?

Lleva tu documento de identidad, una libreta o cuaderno para tomar notas y mucha energía.

¿Qué pasa si llego tarde?

Se recomienda llegar a las 2:00 PM para el registro. Si llegas después de 2:30 PM, podrías perder la ceremonia de apertura y la formación de equipos.

¿El algoritmo de Python es transparente?

¡Absolutamente! El código del algoritmo se mostrará en pantalla antes de ejecutarlo. Cualquier estudiante puede verificar que la distribución es verdaderamente aleatoria y equitativa. El código usa random.shuffle() con seed basado en la fecha actual.
